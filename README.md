# Tap the Black Tiles

A browser-based reaction game developed using HTML, CSS, and JavaScript. Players test their reaction speed and accuracy by tapping black tiles while avoiding incorrect selections.

## Features

* Interactive tile-based gameplay
* Dynamic score tracking
* Real-time interaction using JavaScript DOM manipulation

## Technologies

* HTML5
* CSS3
* JavaScript
* DOM API

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Start playing!
